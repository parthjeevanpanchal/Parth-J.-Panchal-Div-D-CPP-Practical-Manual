Practical 12: Object-Oriented Architecture Specification

Designed strictly to illustrate Encapsulation, Polymorphism, Inheritance, STL Containers, and Robust Exception Handling.

1. Encapsulation

Private member variables (m_id, m_quantity, m_price) protected by invariant setters. Direct balance corruption is impossible.

2. Inheritance & Polymorphism

Base class Item is specialized into PerishableItem and ElectronicsItem. Virtual methods execute dynamically via std::shared_ptr<Item>.

3. STL Containers

std::map<int, shared_ptr<Item>> maintains natural $O(\log N)$ sorted order; std::vector<Transaction> provides sequential audit logging.

4. Negative Stock Guard

Guaranteed negative stock prevention. When amount > m_quantity, InsufficientStockException aborts subtraction cleanly.
