# Parth-J.-Panchal-Div-D-C-Practical-Manual

Div-D C++ Practical Manual by Parth J. Panchal — curated collection of 11 practical lab assignments covering fundamental to advanced Object-Oriented Programming in C++.

**Author:** Parth J. Panchal  
**Division:** Div-D  
**Language:** C++ (C++11/C++14/C++17)

---

## 📚 Practical List & Topics

| Practical | Topic / Concepts Covered | Description |
|---|---|---|
| **[Practical 01](practical01.cpp)** | Basics & Operators | Variables, data types, constants, arithmetic, relational, and logical operators. |
| **[Practical 02](practical02.cpp)** | Classes & Objects | Encapsulation, access specifiers, constructors, and banking operations. |
| **[Practical 03](practical03.cpp)** | Memory & Constructors | Dynamic memory allocation (`new`/`delete`), default, parameterized, and copy constructors, destructors. |
| **[Practical 04](practical04.cpp)** | Smart Pointers | Modern memory management with `std::unique_ptr` and `std::shared_ptr`. |
| **[Practical 05](practical05.cpp)** | Inheritance | Single, multiple, multilevel, and hierarchical inheritance hierarchies. |
| **[Practical 06](practical06.cpp)** | Polymorphism & Abstraction | Abstract base classes, pure virtual functions, runtime polymorphism, and virtual destructors. |
| **[Practical 07](practical07.cpp)** | Overloading | Function overloading and operator overloading (`+`, `<<`) using Complex numbers. |
| **[Practical 08](practical08.cpp)** | Design Patterns | Implementation of the Singleton design pattern. |
| **[Practical 09](practical09.cpp)** | Templates | Generic programming using class templates (`Stack<T>`). |
| **[Practical 10](practical10.cpp)** | Exception Handling | Custom exceptions, `try-catch` blocks, standard exception inheritance. |
| **[Practical 11](practical11.cpp)** | File Handling | Reading & writing CSV files (`students.csv`), file positioning functions (`tellg`, `tellp`, `seekg`, `seekp`). |

## 🛠️ How to Compile & Run

### Prerequisites
- GCC / G++ (MinGW) or MSVC / Clang

### Compilation (using g++)
```bash
g++ practical01.cpp -o practical01.exe
./practical01.exe
```
*(Replace `practical01` with any desired practical filename)*
